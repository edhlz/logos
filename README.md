# Minecraft Server Framework (Rust)

**Work in progress (WIP).** This project is under active development and is not production-ready.

An open-source framework for building **vanilla-compatible Minecraft (Java Edition) servers** in **Rust**, using an ECS approach (Bevy ECS-inspired). This is **not** a plugin/mod server like Bukkit/Spigot/Fabric/Forge.
